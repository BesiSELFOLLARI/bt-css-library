# bt-css-library
Small reusable CSS library (prefix `bt-`) with layout, form, table and badge components.

## Usage
Add this to the `<head>` of your page:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/BesiSELFOLLARI/bt-css-library@v1.1.0/bt.css">
```

## Classes
`bt-container`, `bt-card`, `bt-summary`, `bt-form`, `bt-input`, `bt-btn`, `bt-btn-ok`, `bt-btn-danger`, `bt-table-wrap`, `bt-table`, `bt-row-overdue`, `bt-badge`, `bt-badge-ok`, `bt-badge-warn`, `bt-badge-danger`, `bt-error`
