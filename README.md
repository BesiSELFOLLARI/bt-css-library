# bt-css-library
Small reusable CSS library (prefix `bt-`): container, card, form, input, button, table, badge and summary components.

## Usage
Add this to the `<head>` of your page:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/BesiSELFOLLARI/bt-css-library@v1.0.1/bt.css">
```

## Classes
`bt-container`, `bt-card`, `bt-input`, `bt-btn`, `bt-btn-ok`, `bt-btn-danger`, `bt-table`, `bt-table-wrap`, `bt-badge`, `bt-badge-ok`, `bt-badge-warn`, `bt-badge-danger`, `bt-error`
